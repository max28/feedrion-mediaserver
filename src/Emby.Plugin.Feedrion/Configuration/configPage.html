Feedrion

Watched episodes go to the "TV shows" extension of each linked Feedrion account, the episodes this server holds appear there as "available on this server", and what was watched elsewhere is marked played here. Only TheTVDB ids leave this server — never a title, a file name or a path. Requires Feedrion Premium.

Options

For each server user: whether a series it watches but does not follow in Feedrion yet gets added there (off by default: on a profile shared with the family, nobody else's shows land in "My shows"), whether an episode marked unplayed here is reported to Feedrion, and which libraries are linked. They can be set before linking. How far an episode must be played is set in the Feedrion app.

Users

Link a user, then type the code in the Feedrion app of THAT user (Settings ▸ Integrations ▸ Connected devices).

Ignored series

Nothing about these series is ever sent to Feedrion, for any user: no watch, no "available on this server". A series already in "My shows" is removed in the Feedrion app — once removed there, this server never adds it back.

Activity

The last 50 changes exchanged with Feedrion, newest first, and which way each one went. A watch sent to Feedrion is skipped there when the account does not follow the series — the app's "Recent activity" says so.

Server

Optional. Turns "available on this server" into a link that opens the episode here, in the reader's own browser. Feedrion never connects to it.
