Feedrion

Watched episodes go to the « Séries » extension of each linked Feedrion account, the episodes this server holds appear there as « available on this server », and what was watched elsewhere is marked played here. Only TheTVDB ids leave this server — never a title, a file name or a path. Requires Feedrion Premium.

Users

Link a user, then type the code in the Feedrion app of THAT user (Settings ▸ Integrations ▸ Connected devices). How far an episode must be played, and whether shows never started are followed, are set there, in the app.

Server

Optional. Turns « available on this server » into a link that opens the episode here, in the reader's own browser. Feedrion never connects to it.
